## Update 9.0

**Date:** May 11, 2026

![150+ new models in the catalog](/assets/docs-pages/blog/update-9.0-1.webp)

### 1. 150+ new models in the catalog

SDXL, FLUX and Schnell families have been significantly expanded — realistic portraits, anime styles, NSFW variants, designer and artistic looks. Added **Luma UNI** and **Juggernaut Z** models. Browse them all in the models catalog.

### 2. Recraft Vectorize — SVG generation

Added a brand-new generation type — vector graphics. Three Recraft Vectorize models are supported: one turns a raster image into SVG, two generate SVG directly from text (V4 and V4 Pro). For these models the download menu now has a **"Download SVG"** button — you get clean vectors with no rasterization. Perfect for logos and icons.

### 3. Reworked "Sketch" and "Draft" modes for SDXL and FLUX

They now deliver quality close to "Masterpiece" but several times faster. Convenient for tuning your prompt and trying variants quickly — you can get a good result in seconds without waiting for a full render.

### 4. Unique parameters for proprietary models

Many proprietary models now expose individual extra parameters based on their capabilities: color palettes with weights, special reference modes, web search, "thinking" mode and more. All settings are rendered from each model's own schema — only the ones that actually work are shown. Unused and unsupported parameters are hidden from the interface.

### 5. Styles — only for matching families

Styles are now displayed only for the families they were designed for — **SDXL**, **FLUX** and **Schnell**. For other models the styles section is hidden entirely.

![Cost depends on resolution](/assets/docs-pages/blog/update-9.0-2.webp)

### 6. Generation cost now depends on resolution

Previously the price was averaged. Now the cost is calculated from real resource usage and tied to the chosen size:

- Low resolutions became cheaper, high resolutions — proportionally more expensive.
- The cost badge shows the price in **two places** — under the "Create" button and next to the resolution selector, so you see how size affects price.
- **Live recalculation** when you change size, mode and paid options.
- If an option has a surcharge — **+N coins** is shown right next to the toggle.
- A cost-by-size-and-tier table is available both in the catalog and inside model details.
- Models with mode-dependent pricing get a separate **"Mode → cost"** table.

### 7. Updated models catalog

Redesigned the models catalog and individual model pages.

### 8. Catalog cleanup

Another round of housekeeping: expanded model descriptions, refreshed categories, re-checked and updated settings for every existing model.

## Update 8.3

**Date:** March 16, 2026

![One-Time Password (OTP)](/assets/docs-pages/blog/update-8.3-1.png)

### 1. New Authentication System — One-Time Password (OTP)

We've completely redesigned the login system. You no longer need to remember a password — just enter your email address and receive a one-time 6-digit code. It's simpler, more convenient, and more secure.

**How it works:**

1. Enter your email in the login field
2. Click "Get Code"
3. You'll receive an email with a 6-digit code (valid for 10 minutes)
4. Enter the code — and you're logged in automatically

**OTP advantages:**
- No need to create or remember passwords
- Each code is single-use — more secure than a traditional password
- Works with any email provider, including international ones (Gmail, Outlook, etc.)
- No risk of forgetting your password — a new code is always just an email away

Login via **Yandex**, **VK**, **Odnoklassniki**, and **Mail.ru** is also still available.
